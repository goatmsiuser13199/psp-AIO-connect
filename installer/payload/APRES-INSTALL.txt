psp-connect — apres installation
================================

1) Memory Stick
   Si la copie auto a echoue, copie :
     homebrew\EBOOT.PBP
     homebrew\usb.prx
   vers :
     ms0:/PSP/GAME/psp-connect/

   Ou relance : deploy-stick.ps1 (clic droit → Executer avec PowerShell)

2) Sur la PSP
   - Quitte le mode USB stick du XMB
   - Lance Game → psp-connect
   - Branche le cable USB (reste dans l'app)

3) Driver USB (une seule fois)
   Zadig → Options → List All Devices
   Device 054C:C001 → WinUSB → Install / Replace Driver

4) App PC
   Lance "psp-connect" (Bureau ou menu Demarrer).
   Accepte l'UAC : les droits admin servent UNIQUEMENT a afficher la temperature CPU.
   Sans admin, le dashboard marche, mais la temp CPU reste vide.
