psp-connect — Memory Stick
==========================

FR
--
Copie le dossier "PSP" (a cote de ce fichier) a la racine de ta Memory Stick.
Fusionne avec un dossier PSP deja present si besoin.

Sur la stick :
  PSP\GAME\psp-connect\EBOOT.PBP
  PSP\GAME\psp-connect\usb.prx

Puis sur la PSP : Game → Memory Stick → psp-connect

EN
--
Copy the "PSP" folder (next to this file) to the root of your Memory Stick.
Merge with an existing PSP folder if you already have one.

On the stick you should have:
  PSP\GAME\psp-connect\EBOOT.PBP
  PSP\GAME\psp-connect\usb.prx

Then on the PSP: Game → Memory Stick → psp-connect
